# Notion Handoff v0.1.0

First public release of **Notion Handoff**: publish selected Obsidian notes to work or client Notion workspaces, then pull edits back when you're ready. Every sync is manual; no background publishing or separate CLI required.

## Highlights

- **Push to Notion:** create a page from your note or update its linked page. Review a diff when Notion content has changed, then pull first or explicitly push anyway.
- **Pull from Notion:** merge independent edits automatically. Resolve changes individually with **Take Notion**, **Keep Obsidian**, inline editing, and Undo before saving.
- **Multiple workspaces:** configure separate connections for work and clients. Notes remember their workspace and page; workspace identity checks prevent accidental cross-workspace sync.
- **Images and attachments:** upload embedded images and files; download new Notion images into your configured attachment folder.
- **Editable drawings:** publish Excalidraw and TLDraw embeds as PNG previews while keeping their source drawings editable in Obsidian. The corresponding drawing plugin must be enabled for export.
- **Backups:** save the original note before Pull changes it, retaining the latest five backups per linked note after a successful save.
- **Setup and navigation:** test connections, search for a parent page, and jump to linked pages with **Open in Notion**. Sync history survives token changes within the same workspace.

## Install

Requires **Obsidian 1.5.0 or later**.

1. Install and enable [BRAT](https://github.com/TfTHacker/obsidian42-brat) from **Settings → Community plugins**.
2. In BRAT settings, choose **Add a beta plugin** and enter `cajames/obsidian-notion-handoff`.
3. Select the latest release and enable **Notion Handoff**.

For manual installation, download `main.js` and `manifest.json` from this release into `<vault>/.obsidian/plugins/notion-handoff/`, reload Obsidian, and enable the plugin. Styles are bundled in `main.js`; no separate `styles.css` is needed.

## Connect Notion

1. [Create a Notion integration](https://www.notion.so/profile/integrations) with read, update, and insert content capabilities. Grant access to the pages you want to sync and a parent page for new notes.
2. In Notion Handoff settings, add a workspace name and its integration token or OAuth access token.
3. Click **Test connection**, then **Choose parent page**. Add more connections if needed.
4. Open a note and run **Push to Notion** from the command palette. Later, use **Pull from Notion** to review remote edits.

New pages use the note's `title` frontmatter property, falling back to its filename. Manage existing page titles in Notion; sync does not rename notes or update existing Notion page titles.

## Initial-release limitations

- Mobile installation is enabled, but physical-device end-to-end sync on iOS and Android is not yet verified. Treat mobile support as experimental.
- Individual uploads are limited to **20 MiB**.
- A timed-out Notion write may still complete remotely. Check Notion before retrying a failed page creation or media insertion.
- Pull backups live in the plugin's `backups/` directory. Keep independent vault backups, especially when trying the initial release.
